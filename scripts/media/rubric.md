# 演示视频评分表 rubric（五维，每维 0–2，满分 10）

真源 = `scripts/media/rubric.md`（`scripts/media/judge.py` 把同一份文本发给每个评委席，并复制一份到 M/rubric.md）。
及格线：单席 **总分 ≥ 7**；全片通过 = **3 席中至少 2 席及格**（`judge.py` 的 pass 规则）。

| 维度 | 0 分 | 1 分 | 2 分 |
|---|---|---|---|
| **真实性** | 出现任何不是这个 app 真实界面的画面（生成图、拼贴图、示意图），或旁白描述的动作在画面里根本没发生 | 画面都是真实录屏，但有镜头与旁白对不上（讲 A 演 B） | 每一帧都是真实 app 的录屏，旁白讲的每个动作都能在画面里看到 |
| **清晰** | 看完不知道这个软件是做什么的 | 大致知道是个看板类工具，但主线（捕获 → 闸门 → 批准 → 执行 → 验收）没串起来 | 主线清楚：从捕获到验收每一步都被演示过，观众知道人在哪一步拍板 |
| **可读** | 关键文字糊到读不出，或画面元素被裁切 | 大部分可读，个别镜头字太小 / 滚动太快来不及看 | 分辨率与字号足够，字幕与画面不打架，每个镜头都有静止的一两秒可读 |
| **节奏** | 有镜头明显拖沓（长时间无变化）或快到看不清 | 节奏总体可以，个别镜头过长或过短 | 每个镜头都在 15 s 内，旁白长度与画面时长匹配，段落之间不突兀 |
| **无误导** | 暗示了软件没有的能力，或把演示数据当成真实成果展示 | 没有明显假话，但有夸大（例如「全自动」而画面里明明需要人批准） | 只讲画面里能证实的事；演示数据是虚构的这一点不制造误解；能力边界与降级路径（例如壳没在跑时的复制指令）如实呈现 |

评委只看：视频抽帧（1 fps + 每镜头一张关键帧，下采样、总数有上限）、两条字幕轨、中文旁白的机器转写。
不给评委看代码与本 repo 的任何说明——他们判的是"这段视频本身说清楚了没有、有没有说谎"。
