- **「一键更新」不再在自动部署被拒时报成功（CONTRACT §68.6 追记 / §56.5 追记，决策 D54，issue #309）**：生产机的 checkout 常驻 `release` 分支，`scripts/auto-deploy.sh` 从 2026-09-05T03:06Z 起每 10 分钟写一次 `refused_branch`——到 09-09 共 **539 次**，机器卡在 v1.0.23 而 main 已到 v1.0.98（领先 270 个 commit），上游修好的 bug（#306 的 `exec cd`、终端接管整链、#214 的误铸 pr_red 卡）一个都到不了生产机；而「关于」页两次点「一键更新」都说「已触发自动部署——几分钟后这里的版本会变」（顶栏 `DeployLabel` 同时正确地写着「不在 main，部署暂停」——一个说停了、一个说成功）。修法四件：(1) `GET /api/about` add-only 带 `deploy_state`，**与看板的 `deploy_state` 顶层键同一个 wire 形**（`act/lib/deploy_state.read`，不另造第二套），但由 server **请求时现读文件**而不是读 actd 的投影——actd 死了 / launchd 被 TCC 拦着时投影本身就是陈的，而这一行要回答的恰是「更新链路还活着吗」；缺席 / 坏文件 / reader 抛异常 → `null`，关于页永不 500。(2) `act/lib/deploy_state.py` 立两个状态集合（唯一真源）：`BLOCKING`（`refused_branch` / `refused_dirty` / `blocked_tcc`——提前 kickstart 一轮也清不掉）与 `POISONED`（`failed` / `rolled_back` / `rollback_failed` / `ci_failed`——kickstart 照跑但 `failed_sha` 在 main 挪窝或 `--force` 之前不重试）；`_auto_deploy_fix` 升为 public `auto_deploy_fix`，doctor 行与新的 409 共用同一句修法。(3) `POST /api/update/install` 先读后动：`BLOCKING` → **零 kickstart** + 409 `deploy_refused`（details 带 `deploy_status` / `deploy_detail` / `fix`），其余状态照旧 kickstart 且回执 add-only 带上一轮的 `deploy_status` / `deploy_detail`；「agent 未加载」仍先判（那台机器不走自动部署 → 原生兜底：打开 release 页）。(4) web：`BLOCKING` → 按钮**一进页就禁用** + 「更新链路断着：<状态词> — <拒绝原文>」+ 怎么修（修好后等下一轮，或 `bash scripts/auto-deploy.sh --force`），409 `deploy_refused` 走逐字同一句且**绝不**打开 release 页、**绝不**说「已触发」；kickstart 真发生时 `deferred` 改说「上一轮还在等：<会话闸门原句>，会话散了版本才会变」（kickstart 不带 `--force`，§56.3 的闸门会原样再判一次）、中毒的 sha 改说「<sha7> 在 main 挪窝之前不会被重试」。状态词与两个集合一律从顶栏的 `DeployLabel` 导出复用，顶栏与关于页永不各判一次。判例 `tests/test_server_about_deploy_state.py`、`web/src/components/settings/AboutSection.deployRefusal.test.tsx`。
- **版本号统一为 tag，`+N` 不再当版本给用户看（§56.1 追记）**：`act.__version__` 在 HEAD 领先最近 tag 时是 `X.Y.Z+N`，而生产机的 `+N` 数的是 `release` 分支上 ingest 的数据 commit——2026-09-09 实录关于页说 `1.0.23+92`、`deploy_state` 说 `1.0.23+101`，同一台机器两个版本号，两个数对用户都没有意义。新 `web/src/version.ts`（`releaseVersion` / `aheadCommits` / `aheadNote`，唯一真源）让关于页「版本」行与顶栏部署小字只渲染 `v<tag>`，`+N` 降级成一句「本地领先 N 个提交，未发版」（关于页辅助行 / 顶栏 title）。真源与比较一个字不动：心跳、install_report、`update_check.parse_version`、doctor `version` 行的盖章对账继续用整串（§56.3 第 9 步的逐字相等判据依赖它）。
