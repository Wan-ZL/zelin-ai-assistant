- **可发送长版的每一条现在有一个跨版稳定的名字**：条目前面写的是它自己的节内标签（`D1` / `S2` / `P3`，字母来自节键闭表 decided/split/proposed/deadline/changed/open），重新生成保留同一条承诺的标签（改写也算）、只有新条目才拿新号，而一条被删掉的条目腾出的号**永不再发给别人**——所以几个月后引用「这场会的 D1」指的还是同一条。标签由管线派发、模型永不是作者：它只能在输出里声明一个前缀，未知 / 重复 / 来自另一份纪要的声明一律丢掉重派，模型漏掉的按正文相似度确定性回挂（门与理由 truth = `act/lib/recap_text.py`）。面板因此多一排逐条引用 chip（复制 `2026-08-31 Zoom #D1`，粘出去的正文一字不变），「上一版」的两版对照改按标签比——一条被移动或改写过的条目显示成「改」而不是「新」，而回退把那一版的标签原样搬回来（CONTRACT §63.12，issue #300）。
