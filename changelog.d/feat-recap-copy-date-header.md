- **会议纪要复制出来带日期了（issue #299，CONTRACT §63.5 修订）**：复制键以前只写五行正文，时间只活在详情页标题里、日期只活在左列表的按日分组表头里，两样都不进剪贴板——粘到 Slack / 邮件 / 文档里，收件人看不出这是哪天哪场会，同一天两场会的两份粘贴逐字同形。自此复制 = 一行抬头 + 原样五行，`2026-03-04 (Wed) 14:07–14:48 · Zoom · 41 min`（中文 `2026-03-04（周三）…`），抬头跟着详情页的中文 / English 切换；详情页标题显示的就是这一行，所见即所粘。时间是**录制采集到的原值，不向整点取整**——它是记录，取整会让它读起来像日程。设置 → 会议纪要 多一把「复制时带上日期与时间那一行」（默认开；关掉 = 剪贴板回到只有五行，标题仍带日期；config.yaml `recap.copy_header` / override 键 `recap_copy_header`）。存盘的 recap 文件、Slack 草稿 payload、inbox 动作字段一个不变。
