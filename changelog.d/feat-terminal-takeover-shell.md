- **双击卡片 = 在终端接管会话；单击卡片什么也不做；不再每次弹 "Allow Ghostty to execute …?"（owner 拍板 2026-09-04 + D36 2026-09-06，issue #216）**：卡面的「在终端接管」按钮和「单击复制指令」行都去掉了——双击整张执行中 / 待验收（有会话）的卡，直接在你选的终端（设置「通用 · 终端应用」：Ghostty / Terminal / iTerm2）里新开窗口接上那个会话；要手动复制命令，打开「展开详情 ▸」侧栏，「会话」区有「复制接管指令」按钮；没有会话的卡（提案 / 排队 / 已完成）双击不做任何事，键盘 Enter 仍是打开详情侧栏。背后 server 不再往 $TMPDIR 写一次性 `.command` 脚本再 `open`（macOS 26 对每个这样的文件都弹一次授权，没有「记住我」），而是把请求排进 `state/terminal_queue/`，由 Dock 里的 "Zelin's AI Assistant" 壳经 Apple Events 拉起终端——会弹系统「想要控制 Ghostty」的自动化授权，点允许即可；壳还是 ad-hoc 签名期间，每次自动部署新版本后第一次双击会再弹一次（不是每次双击），稳定签名证书落地后才是一次性。壳没在跑（或看板跑在非 macOS）时双击降级为把指令复制到剪贴板并提示一句；一分钟没被消费的请求两侧自动清掉。设置里的「在终端打开开发会话」与关于页的「在 Terminal 中卸载…」走同一条新通道（壳没在跑时给出可复制的手动命令）。
