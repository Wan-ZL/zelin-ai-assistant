- **双击卡片 = 在终端接管会话；不再每次弹 "Allow Ghostty to execute …?"（owner 拍板 2026-09-04，issue #216）**：卡面的「在终端接管」按钮去掉，指令行改为「单击复制指令 · 双击在终端接管」——单击照旧复制，双击整张执行中 / 待验收（有会话）的卡直接在你选的终端（设置「通用 · 终端应用」：Ghostty / Terminal / iTerm2）里新开窗口接上那个会话；没有会话的卡（提案 / 排队 / 已完成）双击不做任何事，键盘 Enter 仍是打开详情侧栏。背后 server 不再往 $TMPDIR 写一次性 `.command` 脚本再 `open`（macOS 26 对每个这样的文件都弹一次授权，没有「记住我」），而是把请求排进 `state/terminal_queue/`，由 Dock 里的 "Zelin's AI Assistant" 壳经 Apple Events 拉起终端——第一次会弹一次系统「想要控制 Ghostty」的自动化授权，此后安静。壳没在跑（或看板跑在非 macOS）时双击降级为把指令复制到剪贴板并提示一句；一分钟没被消费的请求两侧自动清掉。设置里的「在终端打开开发会话」与关于页的「在 Terminal 中卸载…」走同一条新通道。
