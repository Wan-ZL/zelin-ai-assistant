- **设置页通用区的草稿守则（行为对齐审计 catalog-draft-guards 批；CONTRACT §68.1 追记）**：owner 决策保留「草稿 + 保存」模型，修掉它的两处缺陷并补齐原生数字框与 telemetry 组的守则。(1) 同一区里的即时写者（Slack「监控范围」勾选器、目录字段「创建」）刷新目录时不再整份清掉未保存的草稿——按键合并：你改过的键留着，没改的键跟新值；同一个键两边都动了（文本框里没保存的频道列表 vs 勾选器刚勾的）以刚落盘的为准，不会被下一次「保存」静默撤回；自己「保存」成功后草稿对齐 server 回执。(2) 有未保存改动时离开页面（侧栏 / ⌘数字 / 整页导航）浏览器会先问一声（`beforeunload`），存净即摘；壳的 WKWebView 没有公开的 beforeunload 委托，壳内不弹。(3) 数字框非法（负数 / 留空 / 整数字段填小数）时「保存」禁用、该键不进请求——server 的英文 400 不再露面；只看你改过的格——config.yaml 里既有的越界值原样显示，不锁整区的「保存」；回收站保留天数用原生整句「请输入整数天数，如 60（0 = 永不自动清）」。(4) 「行为事件级别」在「参与产品改进」关掉时禁用，「上传我输入的文本」在总开关关或级别不是「详细」时禁用（原生同款；只禁不改值）。
