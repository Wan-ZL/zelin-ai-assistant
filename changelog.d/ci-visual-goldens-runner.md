- **视觉基线 golden 改由 CI runner 渲染（§66.4 追记）**：新 `workflow_dispatch` 工作流「Refresh visual goldens」（`.github/workflows/visual-goldens.yml`，`ref` 输入默认 main）在与「Web visual (playwright)」**同一** `macos-latest` 镜像、同一 setup 步上跑 `playwright test --update-snapshots=all` 重截六张 golden，再原样比对一次（runner 必须复现自己的输出，否则 job 红并上传 diff），把 `web/e2e/__screenshots__/**` 作为 artifact `visual-goldens` 交出——job 自己不 commit 不开 PR（`GITHUB_TOKEN` 开的 PR 在本仓不触发 CI），人 / agent 下载、覆盖、开 PR。起因：此前每套 golden 都在开发 / agent 的 Mac 上 `visual:update` 出来，与 runner 的文字光栅化（PingFang / Chromium 构建 / hinting）不一致，每个 CJK 字形都「回归」（每张 1–3 % 像素），job 自 2026-09-04 起在 main 上红而背后零 UI 改动。CONTRIBUTING「Visual baselines」写明流程并禁止在 Mac 上再生成待提交的 golden；`npm run visual:update` 降为本地「看自己改了什么」的工具。
