剩余 3 体的等价性：机器判定，不靠肉眼

① int_plus1@556:30 —— 可证等价

line = raw.split("#", 1)[0].strip().lstrip("/").rstrip("/")
                      ↑ 变异成 2

取 [0] 使 maxsplit（≥1）不可观测："a#b#c".split("#",1)[0] 与 split("#",2)[0] 都是 "a"。用 200,584 条字符串语料（穷举小字母表组合 + 定种子 fuzz）对拍裸表达式与 556 行那句完整表达式，counterexample 0 条。

② return_none@438:8 与 @572:12 —— 经唯一调用点不可分

_unpinned():  return False   → return None
dangling():   return False   → return None

全模块唯一消费点分别是 447: if match and _unpinned(match.group(1)): 与 579: if path and dangling(path):，都是纯布尔语境，而 bool(False) == bool(None) == False。要杀只能对私有 helper 的返回值做 is False 身份断言——那钉的是实现细节。本轮按规矩不加新 case，留给 owner 判断值不值。

撞车记录（给下一个 session 的两条操作提醒）

别人留下的探针会污染生产文件

撞车期间共享 worktree 的 skills/test-code/scripts/checks.py 一度带着三个注入的变异体（[:10]→[:9]、[:12]→[:13]、est 240→239）躺在工作区里未提交。
