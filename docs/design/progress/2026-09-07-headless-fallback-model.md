**为什么**：owner 2026-09-07 原话「fable 5.1 用不了的使用 claude code 默认使用了 opus 4.8 这个老模型。能否去掉这个 4.8 这个老模型」→「你就把 claude code 的 backup 模型问题解决就行」。此前本产品从不传 `--fallback-model`，主模型（全局默认 `claude-fable-5-1[1m]` 或旋钮）拿不到时 Claude Code 静默切到它自己的备用——CLI 内置的 `opus` 别名，此刻解析到 Opus 4.8。owner 本机的 `~/.claude/settings.json` 已由 lead 手工写入 `fallbackModel: ["claude-opus-5[1m]"]` 与 env `ANTHROPIC_DEFAULT_OPUS_MODEL`（不在 PR 内）；本 PR 让守护进程侧显式、可移植——新装机不靠个人设置也同样行为。事实核对自 Claude Code 文档（model-config#fallback-models / cli-reference）：`--fallback-model <m1>,<m2>` 交互 / `-p` / `--bg` 皆有效，按序尝试，别名与完整 id 皆收；v2.1.157 起主模型找不到时本会话余下时间切到回退；`ANTHROPIC_DEFAULT_OPUS_MODEL` 决定 `opus` 别名解析到谁。

**做了什么**：(1) `act/lib/config.py` 第三把旋钮 `models_fallback`（出厂值字面 `claude-opus-5[1m]`；`coerce_fallback_model`：None / 空白 → 出厂值、`off` 大小写不敏感与布尔 False → `off`（YAML 1.1 把裸 `off` 读成 False——按文档写必须真的关掉）、形状合法 id 原样、其余 ValueError；yaml 路径坏值回落出厂值而不是 off——配错字不该让 4.8 悄悄复活；overrides 键 `models_fallback` 进 `_OVERRIDE_FIELDS`）。(2) `act/llm.py`：`fallback_model(cfg)` 解析（垃圾 → 出厂值，永不进 argv）；`build_argv` 与 `dispatch_argv` 在 `--model` 之后、变尾（`extra_argv` / `NO_MCP_ARGV` / `--name` / prompt）之前追加 `--fallback-model <id>`；`probe_argv` 刻意不带（探的就是那个 id 答不答）；`runner_env(cfg=None)` add-only 参数，回退开着且 id 以 `claude-opus` 开头时设 `ANTHROPIC_DEFAULT_OPUS_MODEL=<id>`（覆盖继承值；非 Opus 回退不动它——把 `opus` 钉成 Sonnet 是谎话）。`llm.run` / executor 四个发射点 / doctor 探针都传 cfg。(3) actd `_refresh_model_knobs` 每 pass 多刷 `models_fallback`。(4) doctor `claude code model` 行恒带 `fallback: <id>|off`；别名被跟随的 WARN 只在 off 时保留（detail 加「且回退已关」、fix 加「把『回退模型』打开」），回退开着 → OK 并点名回退模型；永不 FAIL 不变。(5) server `GET/PUT /api/settings/models` add-only：`fallback` / `off` / `fallback_default` / `source.fallback`，PUT 第三键 `fallback`，diff-write 同款；回退专用 warning 句（只坏回退路径），出厂值与 off 不告警；手抄常量与 coerce 由镜像判例钉住。(6) web 「模型」section 第三把 `<select>`「回退模型」复用 `ModelKnob`（add-only props `sentinelLabel` / `defaultChoice`）：关闭回退 → `claude-opus-5[1m]（默认）` → canonical → 自定义…；出厂值是固定选项不弹别名警告；留空 = off；一次 PUT 三键。(7) `config.example.yaml` 注释块加 `fallback`。

**有意重钉的 golden / 判例**（argv 多两个 token `--fallback-model claude-opus-5[1m]`）：`tests/test_llm_boundary.py` 全部逐 site 字面（模块 docstring 记明 D53）、`test_self_improve_argv.py`（NO_MCP 现在跟在 `--model` + `--fallback-model` 之后，`argv[-7:]`）、`test_recap_no_egress.py` `PINNED_TAIL`、`test_recap_slack_draft_allowlist.py` argv 尾、`test_doctor_models.py::test_following_a_non_canonical_alias_warns_never_fails`（改为 `models_fallback=off` 下验证）、`test_server_settings_edges.py` / `test_server_settings_models.py`（`source` 多 `fallback` 键）、web `ModelsSection.test.tsx`（PUT 三键）与 `parity.test.tsx` 的 `ModelsSettings` fixture。`tests/test_executor_prompt_golden.py` **零变化**——它钉的是 prompt 正文，不含 argv。
