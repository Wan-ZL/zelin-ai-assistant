**审计发现壳的主菜单是一副硬编码英文骨架**（`shell/Sources/main.swift` `buildMenu`）：About → 系统 About 面板；没有「设置…」⌘, 与「权限体检…」——而权限体检页还挂着「之后随时可从菜单「权限体检」再打开」一句；没有「隐藏其他 / 全部显示」、窗口菜单没有「缩放」；没有 ⌘L「聚焦捕获框」；建一次就不动，页面切 zh/en 时菜单仍是英文。原生 `AppDelegate.installMainMenu` 每个标题都走 `L()`，`Store.swift` `/lang` 与设置页保存后整个重建。§66 清单 `menu.main` 全部 owner=shell、只列不判，所以 `[ui-parity]` 门抓不到。
