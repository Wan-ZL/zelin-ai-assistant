**做了什么**：owner 截图里 52px 定高的 sticky 顶栏（grid `auto 1fr auto`）中缝装着 `flex-wrap: wrap` 的 FilterBar，窄窗口时搜索框 + 五颗 chip + 提建议 / 选择 + 排序 叠成四行、上下溢出压住标题、每日整理条与页面。三个候选——加高换行、横向滚动、收纳——只有收纳不破坏「顶栏是一根定高的条」这条原生形制，于是按实测宽分三档。**为什么量顶栏不量视口**：顶栏宽 = 视口 − 导航栏，导航栏 48 / 200 / 160–320 可折可拖，同一视口下能差 270px。**为什么阈值是 token 而不是「装不下就收」**：装不下再收会在阈值附近来回抖（收起后左右两翼变窄 → 又装得下 → 展开 → 又装不下），而且 jsdom 量不出布局、没法判例；固定阈值 + 两个**静态**加项（壳桥在场 +180 / 英文 +200，只取决于桥与语言）+ 乘 `--text-scale` 覆盖了实测里全部会让内容变宽的因素（1440×900 golden 条件：zh 浏览器 full 内容 ≈ 1030–1105、壳 +180、en +200、compact ≈ 730 / 900），搜索框 `min-width` 再兜阈值附近 80px。**三档**：full 原样；compact 把 Tier / 期限 / 回锅 / 排序 / 清除 / 选择 收进「筛选 · N」按钮的 popover（`FilterPopover`：`role="dialog"`、焦点进面板 / Tab 循环 / 还给按钮、⎋ / 点外面 / 视口变化关；TaskPropertyPicker 的 listbox 本就 portal 进最近的 `[role='dialog']`，所以子弹层天然算「里面」、⎋ 先关子弹层再关面板）；tight 搜索折成放大镜（点它 / ⌘F 展开成行内框、失焦收起、有词带点）、筛选 / 提建议 / 录制 / 实时字幕 只留图标（aria-label = 全档文案，录制状态词挂 title）、左侧只剩标识 + 标题、新鲜度 / 部署小字折进连接点 tooltip（陈旧 / 非 healthy 时点转橙）。FreshnessLabel / DeployLabel 拆成 hook + 渲染两半（HeaderBar 调一次 hook、按档位决定渲成标签还是折进 tooltip，不多起 interval）。

**不变的**：过滤 / 排序 / 多选状态仍只住 store + URL query，收纳与展开不写一个字；⌘F 任何档位聚焦搜索；⎋ 两段（清词 → 收起 / 退出多选）不变，面板开着时 ⎋ 只关面板。jsdom 无 ResizeObserver → 恒 full：§66.2 判卷面（PRESENT 844 / PENDING 15 / MISSING 0 / WAIVED 4，`report.json` 与 main 逐字节相同）与既有判例看到的还是原顶栏；视觉 golden 条件（1440 视口 → 顶栏 1240 ≥ full-min 1220）仍是 full，6 张 golden 预计不变（未重生成）。判例：`headerDensity.test.ts`（10）、`HeaderBar.test.tsx`（+5）、`FilterBar.test.tsx`（+8）、`tokens.test.ts`（+2）。原按视口的 `@media (max-width: 900px / 780px)` 规则退役。
