**补回什么**：原生 `Store.swift:320-324` 对 `dashboard.json` decode 失败的处置是「Keep the previously good dashboard rather than blanking the UI」+ `loadError = L("读取 dashboard.json 失败: ", …) + error.localizedDescription`，`Kanban.swift:60-66` 把它渲染成 header 下一行橙字、看板照常渲染、PipelineHealthBanner 照常说话；`Store.swift:56-57` 的 `@Published var dashboard` 让每次 reload 发布后 sidebar / 展开区都从新快照重渲染。web 移植版：`api.request` 对 2xx 却解不出 JSON 的体 resolve `{}`，`refreshBoard` 把 `{}` 落成 `board`，`BoardLanes` 取 `board.needs_approval` 崩、没有错误边界 → 白页；`selectCard` 一次性拉详情、`refreshBoard` 从不碰 `cardDetail`，D34 后侧栏是唯一详情面且按 `lane` 选积木，开着时全部冻结（含 `TitleEditor` 预填旧名）。第三条从 `composer-keys-esc-history` 批移交：侧栏的 window ⎋ 没有 IME / target 作用域。

**怎么补**：(a) `api.request` 核心：2xx 非 JSON 体合成 `ApiError{status: 真 2xx, code: READ_FAILED, details.failure: "invalid-json"}`（读写一律、不重试；非 2xx 分类不动）。`store.refreshBoard`：先验顶层形状（对象 + 字符串 `generated_at`），任一失败 → add-only `boardDecodeError` = 原生那一行、`board` 不动、`boardError` / `boardMissing` 清；判据 `isBoardDecodeError`（`READ_FAILED` ∧ 2xx）。过了门的快照再经 `normalizeBoardShape` 补列级形状（原生 `Dashboard.init(from:)` / `decodeLossyRows`：缺列 / 坏列 → `[]`、坏 `counts` → `{}`、可选列缺席不补、正常时同一引用）——review 发现一份只带 `generated_at` 的合法 JSON 会原样落地、`BoardLanes` 取 `.filter` 炸进错误边界且旧快照已换掉，本条补上。**没有落 `boardError`**（审计原文建议）：它的六个读者全把它读成「离线」——ErrorBanner 会说「连不上本地服务」、PipelineBanner / DiagnosticsStrip / MaintenanceBanner 一并闭嘴，对着一台在跑的 server 是两句谎话（宪法第 3 条）。渲染：`ErrorBanner` 加 warning 变体（有快照时那一行 + 「下面显示的是最后一次成功加载的看板快照」，离线优先），`AppShell` 加无快照分支（那一行 + 重试）。`main.tsx` 包 `AppErrorBoundary`（类组件，React 错误边界唯一写法）：「看板渲染失败」+ 原话 + 重试（重挂 + `refreshBoard`）；边界面只有一个 live region（`EmptyState` 新增可选 `role`，边界传 `alert`，外层不再套 `role="alert"`——review 指出的 alert>status 嵌套会让辅助技术读两遍）；不冒认「读取 dashboard.json 失败」——边界不知道原因，坏快照自此也进不了 store。(b) `refreshBoard` 在 `generated_at` 变了 ∧ 有选中卡时 `followSelectedCardDetail`：静默重拉，成功且仍停在这张卡才整份替换（`landCardDetail` 与首拉共用落地路，顺带清错、记看过）；不清旧详情、失败不报、同版不拉、首版不拉、`detailFollowSeq` + `selectedCardId` 双守卫丢迟到 / 乱序响应。`DetailDrawer` 渲染零改动（`cardDetail ?? boardRow` 自然跟上）。(c) `DetailDrawer` 的 ⎋ 复用 `FilterBar.escapeBelongsToForeignField` + `isComposing / 229` 两道门。无新 wire 字段、server 零变化、`ui/parity` 报告零变化、视觉 golden 不动。
